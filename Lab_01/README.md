# Лабораторна робота №1

**Студент:** Андрій Смоляк  
**Дисципліна:** Розробка мобільних застосунків  
**Платформа:** Flutter / Dart

## Опис проєкту

Розроблено інтерактивний мобільний застосунок-лічильник. Користувач
вводить ціле число, натискає кнопку «Застосувати» або клавішу Enter,
після чого значення лічильника змінюється.

Для збереження стану застосовано `StatefulWidget` та метод `setState()`.
Уся вхідна інформація перевіряється перед зміною лічильника.

## Реалізована логіка

- Додатне або від'ємне ціле число змінює поточне значення лічильника.
- Команда `Avada Kedavra` скидає лічильник до `0`.
- Текст, дробові числа, спеціальні символи та порожній рядок вважаються
  невалідними.
- Для помилки показується текст під полем введення та `SnackBar`.
- Після успішної операції поле введення очищується.

Приклади введення:

```text
5
-12
Avada Kedavra
```

## Структура реалізації

- `lib/main.dart` — запуск застосунку та налаштування теми.
- `lib/counter_page.dart` — інтерфейс і управління станом лічильника.
- `lib/counter_logic.dart` — розбір введення та валідація.
- `test/counter_logic_test.dart` — перевірка логіки парсинга.
- `test/widget_test.dart` — перевірка роботи віджетів.
- `.github/workflows/validation.yaml` — перевірка кодової бази в CI.
