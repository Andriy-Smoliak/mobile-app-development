# Лабораторна робота №2.1

Окремий Flutter-проєкт для UI-застосунку «Розумний дім». Каталог має назву
`lab_2.1`; для сумісності з правилами іменування Dart пакет називається
`lab_2_1`.

## Реалізовано

- Екрани входу, реєстрації, дашборду, профілю та деталей пристрою.
- Іменовані маршрути `Navigator 1.0`.
- Статичні демонстраційні дані для IoT-пристроїв.
- Повторно використовувані кнопка та картка пристрою.
- Адаптивна сітка на основі `LayoutBuilder`; форми й сторінки прокручуються
  на вузьких екранах.
- Єдина тема кольорів і стилів.

## Запуск і перевірка

```powershell
flutter pub get
flutter run
flutter analyze
flutter test
```

Проєкт відповідає методичним вимогам до UI-шару: декомпозиція на екрани та
віджети, навігація, mock-дані й адаптивне компонування. Авторизація та керування
пристроями є демонстраційними й не підключені до бізнес-логіки.
